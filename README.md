# Credit Score Classification using Machine Learning

## Project Overview
This project uses machine learning to classify individuals into different credit score categories based on financial and personal attributes. A **Random Forest Classifier** is used to train the model and predict credit score categories.

## Technologies Used
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- Jupyter Notebook

## Workflow
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature preparation and train-test splitting
- Model training using Random Forest Classifier
- Model evaluation using accuracy, precision, recall, and F1-score

## Key Learnings
- Data preprocessing and visualization
- Supervised machine learning
- Classification model development and evaluation

## Conclusion
This project demonstrates how Random Forest can be applied to credit score classification and provides practical experience in building and evaluating a machine learning model.
